## 1. 概述

本文檔定義 HUSKY-SORTER-001 的備件庫存管理策略，確保硬體到位後系統能夠持續穩定運行，並將停機時間降至最低。

### 1.1 設計原則

- **關鍵備件常備**：磨損件/易損件至少備2套
- **非緊急備件按需**：一般零件可在故障後72h內訂購
- **批次安全庫存**：烘豆機廠商建議的安全批次量（250g/批次 × 20批次 = 5kg）

### 1.2 硬體到位前庫存檢查清單

```
□ 備件套裝（見第2節）
□ 耗材套裝（見第3節）
□ 工具套裝（見第3節）
□ 緊急聯絡清单
```

## 4. 備件更換流程

### 4.1 緊急更換（停機中）

```
1. 識別故障件（見 DEBUGGING_GUIDE.md）
2. 從備件盒取出替換件
3. 記錄更換時間和原因
4. 執行更換（按接線指南操作）
5. 系統POST自檢驗證
6. 更新備件庫存表（見附錄A）
7. 訂購補充備件
```

### 4.2 預防性更換（運行中）

```
1. 健康監控系統預測性告警觸發
2. 評估剩餘使用壽命
3. 計劃停機窗口（2h）
4. 備件更換
5. 标定驗證
6. 更新維護記錄
```

## 5. 庫存管理策略

### 5.1 庫存複查週期

| 備件類別 | 複查頻率 | 觸發條件 |
|----------|----------|----------|
| 關鍵備件 | 每月 | 庫存 < 2件 |
| 一般備件 | 每季度 | 庫存 < 1件 |
| 耗材 | 每週 | 庫存不足1週用量 |

### 5.2 庫存警戒值

```
A類（關鍵）：安全庫存 ≥ 2，警戒線 2（立即訂購）
B類（重要）：安全庫存 ≥ 1，警戒線 1（提前訂購）
C類（一般）：安全庫存 ≥ 1，警戒線 0（按需訂購）
```

### 5.3 年度備件預算

| 類別 | 預算 ¥ |
|------|---------|
| 機械備件 | 500 |
| 電氣備件 | 800 |
| 感測器備件 | 600 |
| 耗材 | 400 |
| **合計** | **2,300/年** |
