## 1. 場地概述

### 1.1 機台尺寸與重量

| 項目 | 規格 |
|---|---|
| 機台尺寸（長 × 寬 × 高） | 約 400 × 300 × 500 mm |
| 機台重量 | 約 8 kg |
| 包裝尺寸（含木箱） | 約 600 × 500 × 700 mm |
| 包裝總重量（含配件） | 約 18 kg |

> **注意：** 以上尺寸為不含送料斗及收集桶的基本機台尺寸。安裝時請預留足夠空間以安裝附屬配件。

### 1.2 最小間隙需求

為確保操作便利性、日常維護及散熱效果，機台四周須保留以下最小間隙：

```
        ┌─────────────────────────────┐
        │      前方操作區（≥500mm）     │
        │                             │
        │  左  機  台  右            │
   ≥    │  側  ███  側   ≥            │
  500   │  ≥   ███  ≥   500           │
  mm    │ 500  ███ 500  mm            │
        │  mm     ███  mm             │
        │       ███                    │
        │      後方服務區（≥500mm）     │
        └─────────────────────────────┘
```

| 位置 | 最小間隙 |
|---|---|
| 機台上方（散熱/維修） | ≥ 300 mm |
| 機台前方（操作/取樣） | ≥ 500 mm |
| 機台後方（電氣接線/氣源） | ≥ 500 mm |
| 機台左側（電氣維修） | ≥ 500 mm |
| 機台右側（氣路維修） | ≥ 500 mm |

### 1.3 地板載重

| 項目 | 要求 |
|---|---|
| 地板承重能力 | ≥ 50 kg/m² |
| 建議地面類型 | 防靜電地板、環氧树脂地坪或同等強度地面 |
| 地面平整度 | 水平誤差不超過 3mm/m |
| 地面水平要求 | 無明顯傾斜（傾斜角度 ≤ 1°） |

> **警告：** 地板承重不足可能導致機台震動偏移，影響分選精度。若現場地面承重不足50kg/m²，須進行加固處理。

## 2. 電氣需求

### 2.1 電源規格

| 項目 | 規格 |
|---|---|
| 電源類型 | 220V / 50Hz 單相交流 |
| 專用迴路容量 | 最小 10A |
| 電源線徑 | ≥ 2.5 mm²（銅芯） |
| 插座類型 | 符合 GB 1002 / BS 1363 標準之接地三孔插座 |
| 保護裝置 | 具過載保護之10A小型斷路器（MCB） |

### 2.2 功耗規格

| 工作狀態 | 功耗 |
|---|---|
| 待機功耗 | ~30W |
| 正常運行功耗 | ~120W |
| 峰值功耗（含空壓機） | ~300W |

> **注意：** 峰值功耗出現在空壓機啟動瞬間（約1-2秒）。設計電源系統時請以此峰值為準。

### 2.3 UPS 不斷電系統建議

為保護 Raspberry Pi 主機板及感測器模組，强烈建議配置UPS：

| 項目 | 建議規格 |
|---|---|
| UPS 容量 | 最小 500VA / 300W |
| UPS 类型 | 在線互動式（Line-Interactive）或在線式（Online） |
| 輸出波形 | 仿正弦波（Pure Sine Wave） |
| 備援時間 | 建議 ≥ 10 分鐘（足以安全關機） |
| 保護對象 | Raspberry Pi、相關感測器、網路交換機 |

> **建議：** 壓縮空氣系統（空壓機）無需接入UPS，但控制系統（Pi + 感測器）必須接入。

### 2.4 接地要求

| 項目 | 要求 |
|---|---|
| 接地類型 | 保護接地（ Protective Earthing） |
| 接地導線線徑 | ≥ 2.5 mm²（銅芯） |
| 接地電阻 | < 10 Ω（測量點：機台接地端子至大地） |
| 接地端子位置 | 機台背面左側，標有 ⏚ 符號 |
| 接地排連接 | 建議連接至建築物專用接地排 |

> **警告：** 未正確接地可能導致感測器讀數不穩定及潛在的電擊風險。

### 2.5 電源品質要求

| 項目 | 允許範圍 |
|---|---|
| 電壓穩定性 | 額定電壓 ±10%（198V – 242V） |
| 頻率穩定性 | 50Hz ± 2%（49Hz – 51Hz） |
| 諧波失真率（THD） | < 5% |
| 電壓瞬變 | 不超過額定電壓 ±15%，持續時間 < 50ms |
| 間歇性干擾 | 不允許 |

> **建議：** 若現場電源品質不穩定（如經常性電壓波動大於±10%），建議在電源入口處安裝額定容量≥500W之穩壓器（AVR）。

## 3. 環境條件

### 3.1 溫度條件

| 條件類型 | 溫度範圍 |
|---|---|
| 正常運行溫度 | 15°C – 35°C |
| 短期存放溫度 | -10°C – 50°C |
| 建議最佳運行溫度 | 22°C – 28°C |
| 溫度變化率 | 不超過 5°C/小時 |

> **注意：** 溫度超出正常運行範圍會影響光學感測器精度及氣動元件性能。

### 3.2 相對濕度條件

| 條件類型 | 相對濕度 |
|---|---|
| 正常運行濕度 | 30% – 80% RH（非凝露） |
| 建議最佳運行濕度 | 45% – 65% RH |
| 存放濕度 | < 90% RH |
| 露點溫度 | 必須低於機台外殼表面溫度 |

> **警告：** 高濕度環境（>80% RH）可能導致光學鏡頭起霧，嚴重影響分選精度。嚴禁在凝露條件下運行。

### 3.3 海拔高度

| 海拔範圍 | 影響說明 |
|---|---|
| 0 – 1000m | 正常運行，無降額要求 |
| 1000 – 2000m | 需降額使用，散熱效率下降約5-8% |
| > 2000m | 請聯繫供應商評估特殊配置 |

### 3.4 光照條件

| 項目 | 要求 |
|---|---|
| 機台運行時光照環境 | 機台在封閉暗箱內運行，外部光照不受限制 |
| 鄰近區域光照 | < 100 lux（便於操作員記錄及觀察） |
| 直射陽光 | 應避免直射機台外殼，以免影響外殼溫度 |

### 3.5 防塵 / 防污染

| 項目 | 等級 |
|---|---|
| 機台防護等級 | IP20 |
| 粉塵要求 | 避免高粉塵環境（咖啡加工廠除塵系統完善者除外） |
| 腐蝕性氣體 | 嚴禁存在（如 SO₂、H₂S 等） |
| 油脂蒸汽 | 避免（如附近有加油站、机械维修间） |

> **建議：** 定期清理機台外殼進風口灰塵（約每週一次，高粉塵環境縮短頻率）。

### 3.6 震動條件

| 項目 | 要求 |
|---|---|
| 機台附近最大允許震動 | < 0.5g（峰值加速度） |
| 震動頻率限制 | 避免與機台內部元件（如相機支架）產生共振 |
| 禁止震動來源 | 大型風機、衝壓設備、空壓機（無減震墊安裝時） |

> **建議：** 空壓機應安裝減震墊，並與機台保持≥1m距離。

## 6. 壓縮空氣需求

### 6.1 空壓機規格

| 項目 | 要求 |
|---|---|
| 空壓機類型 | 渦旋式（Scroll）或螺桿式（無油潤滑） |
| 排氣壓力 | 8 bar（116 psi） |
| 流量 | 依機台需求（見下表） |
| 儲氣罐容量 | 最小 50 L |
| 潤滑方式 | 無油（Oil-Free） |
| 噪音等級 | < 75 dB(A)（1m距離） |
| 電源需求 | 220V/50Hz，功率視型號而定 |

#### 空壓機流量計算

| 消耗項目 | 流量需求 |
|---|---|
| 分選噴嘴（×5grade） | ~20 NL/min |
| 氣動執行器 | ~10 NL/min |
| 安全係數 | × 1.5 |
| **最小需求流量** | **≈ 45 NL/min** |

### 6.2 氣管規格

| 項目 | 規格 |
|---|---|
| 氣管外徑 | 6 mm |
| 氣管內徑 | 4 mm |
| 氣管材質 | PU（聚氨酯）或尼龍 |
| 建議使用管色 | 藍色（壓縮空氣專用） |
| 最大氣管長度 | 20 m（超過需加大管徑或增加儲氣罐） |
| 氣管彎曲半徑 | ≥ 20 mm |

### 6.3 空氣品質要求（ISO 8573-1:2010）

| 污染物類型 | 等級 | 具體要求 |
|---|---|---|
| 固體粒子 | Class 1 | 顆粒大小 0.1 – 0.5 μm，濃度 < 0.1 mg/m³ |
| 水份（露點） | Class 2 | 露點溫度 ≤ -40°C |
| 含油量 | Class 1 | 總含油量 < 0.01 mg/m³（無油壓縮機已滿足） |

> **要求：** 必須使用無油空壓機。如使用有油空壓機，必須配備0.001μm精細油水分離器。

### 6.4 除水與自動排水要求

| 項目 | 要求 |
|---|---|
| 前置冷凝排水器 | 必須安裝於空壓機出口處 |
| 乾燥方式 | 冷冻乾燥機（冷乾機）或吸附式乾燥機 |
| 自動排水閥 | 儲氣罐及冷凝排水器須配備自動排水閥（電子式定時排水） |
| 排水頻率 | 建議每 30 分鐘排水一次，每次 3 – 5 秒 |

## 8. 供應商到貨前的準備工作

### 8.1 電源插座安裝

1. **位置確認：** 在機台後方牆面或地面插座的 1.5m 範圍內，確認有一個符合標準的接地三孔插座。
2. **專用迴路：** 確認該插座由獨立的 10A 斷路器控制，不與其他大功率設備共用。
3. **電壓驗證：** 使用電錶測量插座電壓，確認在 198V – 242V 範圍內。
4. **接地驗證：** 使用接地電阻表測量插座接地端子至大地電阻，確認 < 10 Ω。

### 8.2 壓縮空氣管線鋪設

1. **管線規劃：** 從空壓機（或乾燥系統出口）沿牆面或地面布線至機台後方右側（氣動入口側）。
2. **管徑選擇：** 使用 6mm 外徑 PU 氣管。
3. **彎曲半徑：** 確保所有彎頭的彎曲半徑 ≥ 20mm，避免打折。
4. **管線固定：** 使用專用管卡固定，每 0.5m 設置一個管卡。
5. **標示：** 在氣管上黏貼「壓縮空氣」標籤。
6. **末端處理：** 在機台預定位置預留 1m 餘量，末端使用束線帶臨時封口防止污染。

### 8.3 網路線安裝

1. **線纜規格：** 使用 CAT5e 或 CAT6 遮蔽網路線。
2. **路由規劃：** 從網路交換機（或路由器）布線至機台背面。
3. **長度控制：** 保持總長度 ≤ 100m，並預留 2m 餘量。
4. **接頭製作：** 兩端使用 RJ-45 接頭，T568B 線序。
5. **線纜保護：** 穿越牆壁或地面時使用線纜保護管。

### 8.4 機台開箱與組裝區域準備

| 項目 | 要求 |
|---|---|
| 開箱區域 | 機台包裝箱放置處，面積 ≥ 2m² |
| 組裝平台 | 平整、堅固的工作檯或地面，面積 ≥ 1.5m² |
| 工具備妥 | 十字螺絲起子、內六角扳手（依說明書附件清單） |
| 照明條件 | 工作區域照度 ≥ 300 lux |
| 包裝廢棄物處理 | 準備垃圾袋或收集箱，木箱由供應商回收或自費處理 |
