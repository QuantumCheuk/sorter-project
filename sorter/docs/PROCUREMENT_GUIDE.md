## 7. 采购前检查清单

### 收到组件后必做

- [ ] **外包装检查**：破损/进水/变形
- [ ] **型号核对**：与订单规格一致
- [ ] **数量清点**：防止漏发
- [ ] **功能初验**：
  - [ ] Pi 4B：刷入Raspbian，确认启动
  - [ ] Camera：接上Pi，用`raspistill`测试拍摄
  - [ ] HX711：用万用表测供电是否正常
  - [ ] ESP32：用Arduino IDE刷入空白固件，测串口
  - [ ] 步进电机：手转轴确认无卡阻
  - [ ] 电磁阀：通电测试开闭声音
  - [ ] 风扇：通电确认转动
- [ ] **记录序列号**：Pi序列号/HX711批次号等
- [ ] **拍照存档**：记录组件状态
- [ ] **组件暂存**：防潮箱保存，ESD防护
